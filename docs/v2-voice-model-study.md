# V2 empirical voice model study

Research date: 2026-08-24. This is a capability and deployment study, not a universal ranking. Claims below come from current official repositories, model cards, papers, or hosted-provider documentation. Hardware figures are only repeated where the publisher supplied them; unmeasured CPU, Apple Silicon, VRAM, and quality fields remain unknown rather than estimated.

## Selection guidance

- Use Kokoro when an offline, small, permissively licensed preset narrator is enough.
- Evaluate Qwen3-TTS first when one local family must cover preset voices, description-driven design and authorized zero-shot cloning. Its separate checkpoints mean model residency and GPU budgeting still matter.
- Evaluate CosyVoice 3 when Mandarin, Chinese dialects, cross-lingual cloning and streaming are central.
- Consider IndexTTS 2.5 when explicit duration and pronunciation control outweigh its licensing and deployment constraints.
- Do not select F5-TTS pretrained weights as the default commercial path because the official weights are non-commercial.
- Treat Fish S2 as research-license-gated until counsel or the licensor confirms the intended product/SaaS use.
- Hosted providers can reduce deployment burden, but consent, deletion, data retention, eligibility, regional availability, pricing, and voice-token handling remain provider-specific obligations.

## Architecture consequences

The runtime therefore negotiates `VoiceCapabilities` instead of branching on provider names. Provider timestamps are accepted only when present and trustworthy; otherwise generated speech uses the existing alignment layer. Local or remote cloning cannot activate without explicit consent metadata and a preview approval. License metadata is attached to VoiceProfile/SpeechAsset where known, but this matrix is not legal advice.

## Measurement gaps

No local Qwen3-TTS, CosyVoice, Fish S2, IndexTTS or F5 weights were installed in this environment. No hosted voice credentials or custom-voice eligibility were available. Consequently this milestone does not claim measured speaker similarity, WER/CER, first-audio latency, RTF, VRAM, peak memory, long-form drift, cross-language consistency or loudness variance for those providers.
